# Primitive Time 1.0

PWA gratuita para Android/iPhone. Biblioteca de 40 ejercicios, seis categorías y perfiles Walter, Nacho y Bastian. Guarda marcas **reales** de 1RM y 8RM con fecha, historial y respaldo JSON.

## Publicar con GitHub Pages
1. Crear repositorio público `primitive-time`.
2. Subir **el contenido** de esta carpeta a la raíz del repositorio (no subir el ZIP).
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Abrir `https://TU-USUARIO.github.io/primitive-time/`.
5. Android: Chrome → Instalar / Añadir a pantalla principal. iPhone: Safari → Compartir → Añadir a pantalla de inicio.

## Datos y seguridad
Se guardan localmente con `localStorage`; no hay sincronización ni cuentas. Los tres perfiles son selectores locales sin contraseña: no son controles de privacidad. Exportar respaldos desde Ajustes para preservar datos. Importar un respaldo **reemplaza** los datos del dispositivo.

## Reglas de peso
Mancuernas: peso por mancuerna. Unilaterales: carga por brazo. Máquinas: carga mostrada. En sentadilla libre/barra, registrar peso total incluida la barra.
